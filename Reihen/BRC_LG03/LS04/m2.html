Sekundärforschung wertet vorhandene Daten aus, beispielsweise Auftragsstatistiken, Reklamationen oder bereits veröffentlichte Studien. Sie ist meist schnell, kann aber andere Zeiträume, Zielgruppen oder Marktgrenzen betreffen. Primärforschung erhebt neue Daten für eine konkrete Frage. Ein vorhandener Befragungsdatensatz ist für sein ursprüngliches Erhebungsteam ein Primärergebnis, für eine spätere Wiederverwendung eine vorhandene Quelle.
