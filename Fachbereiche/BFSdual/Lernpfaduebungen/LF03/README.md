# Lernpfadübungen zu Lernfeld 3

Beschaffungsprozesse organisieren und wirtschaftliche Entscheidungen treffen

Die Übungen beruhen auf den Übungsaufgaben aus dem Moodle-Board.
Je Paket gibt es 12 Aufgaben für Orientierung, 12 für Anwendung, 6 Transferentscheidungen und 48 Reserveaufgaben für die Festigung. Unter 66 % öffnet sich eine gezielte Festigungsrunde. Das beste Ergebnis je Kernaufgabe zählt. Die Antwortmöglichkeiten werden bei jedem neuen Versuch neu gemischt. Beim Fortsetzen bleibt ihre Reihenfolge erhalten.
