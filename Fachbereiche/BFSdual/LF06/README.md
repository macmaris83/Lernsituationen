## Im Unterricht verwenden

Je Lernsituation die SCORM-ZIP in Moodle als **Lernpaket (SCORM)** hinzufügen. Für eine lokale Vorschau die ZIP entpacken und **scorm.html** öffnen. Über **Editor** in der Fußleiste können Lehrkräfte direkt zu einer Station springen.

Der **GoodNotes-Export** liefert das Arbeitsblatt zur jeweiligen Phase. **Gesamtdokument als PDF** öffnet den A4-Druck. Ab **Informieren** steht der **Löppt-Pilot** zur Verfügung.

In **Bewerten** geben die Lernenden über Peer-Feedback eine Rückmeldung zum Handlungsprodukt. In **Reflektieren** beantworten sie das Moodle-Feedback zur Lernsituation. Die Moodle-Verknüpfungen sind im Editor prüfbar und können dort an den jeweiligen Kurs angepasst werden.
