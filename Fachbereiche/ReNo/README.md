# ReNo

Hier kommen die künftigen ReNo-Lernsituationen hinzu, gegliedert nach den tatsächlich
verwendeten Lernfeldern und Lernsituationen. Es sind noch keine Fachinhalte angelegt.

Die gemeinsame Arbeitsweise, Vorlagen und Bedienung bleiben erhalten. Jede neue
Lernsituation wird einmal als Master registriert und anschließend im selben Ordner
weiterentwickelt. Siehe [MASTER.md](../../MASTER.md).
