# ReNo

Für neue ReNo-Lernsituationen steht der [LS-Master im BRC-Design](../../Vorlagen/LS-Master/) bereit. Er zeigt die acht Phasen und die zugehörigen Aufgaben- und Materialseiten an einem BRC-Beispiel.

ReNo-Lernsituationen werden unter ihren tatsächlichen Lernfeldern und LS-Nummern angelegt. Jede erhält eine eigene Paketkennung und einen Eintrag im [Master-Katalog](../../master-katalog.json). Die gemeinsame Gestaltung kommt aus dem [Formmaster](../../Formmaster/README.md). Die Arbeitsschritte für die Anlage und den Export stehen in [MASTER.md](../../MASTER.md).
