# BFS dual · Glossarlupe

Glossareinträge werden von Begriffen im Material und in den Fachbegriffschecks verlinkt. Das Linkziel kombiniert die ID des Begriffs mit der aufrufenden Seite und ihrer Textmarke. Im Dialog bleibt der Eintrag vollständig lesbar. Der Rücksprung respektiert Browser-Verlauf und Textmarke. In LS 6.9 läuft der Dialog im geöffneten SCORM.

`build.py` dokumentiert die Übernahme der vorhandenen Glossare. Die Laufzeitdateien im Arbeitsmaster gehören in das SCORM-Manifest. In der Druckfassung stehen Glossarverweise am jeweiligen Fachbegriff.
